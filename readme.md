# SISTEM PERSEDIAAN FLORIST

Sistem informasi sederhana untuk mengelola persediaan
pada toko florist.

## Teknologi

- HTML
- CSS
- JavaScript
- Supabase
- PostgreSQL

## Entitas

1. Supplier
2. Produk
3. Transaksi
4. Detail Transaksi

## Fitur

- Dashboard
- CRUD Supplier
- CRUD Produk
- CRUD Transaksi
- Pencatatan barang masuk
- Pencatatan barang keluar
- Perubahan stok otomatis
- Laporan persediaan
- Perhitungan nilai persediaan
- Peringatan stok minimum

## Cara Menjalankan

1. Buat project di Supabase.

2. Buka SQL Editor pada Supabase.

3. Copy seluruh isi database.sql.

4. Jalankan SQL.

5. Buka Project Settings pada Supabase.

6. Salin Project URL.

7. Salin anon/public key.

8. Masukkan keduanya ke file script.js.

9. Buka frontend/index.html.

10. Sistem siap digunakan.
